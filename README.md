# AstrBot 定制优化版

基于 [AstrBot 原版项目](https://github.com/AstrBotDevs/AstrBot) 的本地定制快照，首次音色版导出日期为 2026-10-31，最近修复、模型预设与小七人格说明同步于 2026-11-03，核心版本为 4.27.2。本项目与原版有定制差异，并非官方发行版。

## 持久任务与共享工具（2026-11-03）

修复官方定时工具包装时重复添加 `action` 必填参数、导致聊天和任务入口校验失败的问题；新增真实官方工具注册、缓存复用和入队回归。工具定义错误现在单独提示，内部异常不再统一误报模型配置问题。

- 任务独立入队并保存模型、状态、步骤、错误和工具回执；重启后对结果不明的操作先核实，避免忘记任务或重复执行。
- 回复模型可以依据当前用户要求补交中枢漏判任务，程序仍统一核验权限和去重。主要用户可按机器人、群和真实账号授权群友。
- Windows 文件、命令和依赖安装使用经实际验证的受限账户；任务工作目录独立于机器人程序，全局工具库位于 `C:\AstrBotTasks\tools`。
- 新增网页任务管理与共享工具上传；包含通用文档工具箱和批量 UTF-8 转换脚本，上传不自动执行。部分文档功能需要另装依赖。
- 任务默认 90 秒未完成才补进度，完成／失败另行通知；定时提醒及资讯监测按任务保存时间与通知策略。

部署边界、工具使用和依赖见 [持久任务与共享工具](docs/持久任务与共享工具.md)。人格、模型预设、克隆音频与启动器保留原字节；真实任务库、聊天、密钥和账户凭据不随源码发布。

## 聊天备用兼容修复（2026-11-03）

修复旧路由禁止 DeepSeek 聊天备用、导致请求在调用 Gemini 前被 ValueError 中止的问题。任务进度通知和结果整理也可使用配置的 DeepSeek 备用，仍保留模型启用与端点校验。

本次相关回归87项测试、23项子测试通过，Ruff E9/F821与UTF-8编译通过，仅两项既有依赖弃用警告。未调用真实模型或发送QQ测试；模型预设、人格、音色及启动器保持原值。

## 定时任务、进度与参考图修复（2026-11-03）

- 定时提醒进入任务工具链，以真实工具回执判断创建结果；任务未实际执行时沿用既有主备处理，避免聊天中口头承诺成功。
- 按当前请求用途区分任务模型与聊天模型错误，任务超时不会再误报聊天模型不可用。
- 确认回复发出、开始执行任务后计时，满90秒仍未完成才查询并补一次进度；任务已完成或失败时丢弃迟到进度。
- 支持无消息ID的内联引用图，按当前机器人、用户和会话保存原图引用；“以这个为参考图”等指代可取到同一会话图片。
- 中枢明确批准参考图生成后，继续承接同一用户“按刚刚要求重新生图”等重试；模型自行填改图参数不能扩大权限，群聊他人裸追问不能承接任务。
- 聊天主模型为 `google_gemini_openai/gemini-3.8-flash`，备用改为 `deepseek/deepseek-flash`；后台任务和中枢保持既有配置，均可在网页修改。
- 小七人格说明同步服务器最新版本，JSON、Markdown及干净种子库一致；晚柠、人格示例对话、两份参考音频及启动器保持原版。

本次公开副本定向回归275项测试、95项子测试及独立图片安全8项通过，另有7项初始化与更新阻断检查通过；仅两项既有依赖弃用警告。不代表全仓测试或真实模型、QQ发送验收，未将真实聊天、记忆、账号、密钥或持久提醒导入公开副本。

## 中枢任务追问修复（2026-11-02）

- 私聊中枢读取当前会话最近的用户与助手文本，最多8条、3000字符；过滤系统提示、工具结果和媒体地址，同一消息复用读取结果与模型决定。
- 结合原始要求理解“那你现在调用”等执行追问，区分状态查询、完成和取消，避免丢失任务意图或重复执行；私聊未知身份不会被套用群聊旁观规则。
- 群聊缺少本人近期上下文和本人任务的裸追问进入澄清，清空执行动作与任务分段，防止误承接其他群友任务。

公开副本中枢、群参与与任务生命周期组合回归223项测试、80项子测试通过，另有7项初始化与更新阻断检查通过；只有两项既有依赖弃用警告。以上为定向验证，未使用公开副本调用真实模型或发送消息。人格、脱敏模型配置、音色与启动器保持既有版本。

## 图片与任务回复修复（2026-11-02）

- 纯图片和表情包在取得可靠视觉结果后再构造回复，结合近期语境回应；直接传图时不会再误注入“没有视觉信息”的提示。
- 补充文字与延迟纯图明确分配处理权，避免重复回复；中枢决定不接话时保持安静。
- 图片工具能够读取缓冲参考图，并按同一会话解析“刚才”“这个图”“该图”等明确指代；不同机器人、用户和群聊之间保持隔离。
- 改图类型别名 `image_edit` 正确归一为 `edit`，同时严格保留中枢改图权限检查。
- 图片实际投递成功后停止迟到的等待进度和兜底文字；真实后续步骤仍可继续报告进度。

本次公开副本的图片、图库与任务回复组合回归216项测试、47项子测试通过，另有7项初始化与更新阻断检查通过。仅有既有依赖弃用警告。以上为定向验证，不代表全仓测试全部通过；未使用公开副本连接真实模型或QQ。人格、脱敏模型预设、双机器人音色和启动器继续沿用语音版，内置自动更新仍关闭。

## 既有优化

- 同一消息在同一机器人上的中枢判定复用；多次钩子经过相同消息时复用已有决定，真实消息、媒体和任务变化仍可必要重判。
- 网页可独立切换群消息合批、上下文压缩、人格摘要和判定复用；本次预设四项均开启，合批窗口2.5秒，近期消息上限6条。
- 群聊明确@对象隔离，并抑制机器人之间不必要的接话；已发送回复的待处理队列正常回收，过期请求不能继续发送。
- 裸@回复明确绑定当前发言者，只承接同一发言者120秒内的最近未答消息；正常关闭回复生成器不再误报“主动回复失败”。
- 当前模型配置及小七、晚柠人格重新导出；保留按机器人分开的人格、聊天与后台任务分工和备用模型配置，真实密钥和私人运行资料已清理。

此前路由优化的运行版自动回归为208项测试及53项子测试通过；一轮真实群聊中7个中枢事件仅产生7次实际请求并复用13次，未见串台或互聊延续。这些是原运行实例的验证记录，不能代替重新配置后的部署验收；连续补话合并和裸@承接问题仍应做定向实聊测试。

## Windows 首次使用

1. 安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)；项目需要 Python 3.12 或以上版本，uv 可以管理 Python 环境。
2. 安装 [Microsoft .NET 8 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/download/dotnet/8.0)。请选择桌面运行时，启动器依赖 Windows Forms。
3. 在本目录打开 PowerShell，运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\初始化环境.ps1
   ```

4. 双击 `AstrBot启动器.exe`，点击启动；打开 <http://127.0.0.1:6185> 完成后台账号设置。
5. 在模型来源中填写自己的 API 密钥；在机器人配置中填写自己的平台凭据，再启用需要的机器人。导出预设中的机器人均默认关闭。
6. 检查人格、唤醒词、群聊允许范围、插件目标对象和表情库绑定；原来的私人群号、群友资料及素材库没有随包提供。

EXE 仅是启动管理器，不能代替 Python、依赖和机器人主程序。它必须与 `AstrBot-master` 文件夹放在同一级。若本机已有机器人占用 6185 端口，请先关闭原实例，避免打开原实例的后台。

自学习插件保留原有数据库类型配置；外部数据库地址、库名、账号和密码已清空，使用前须重新配置或在该插件设置中选择 SQLite。其他依赖外部服务的插件也需要重新填写凭据。

## 其他系统或命令行启动

```sh
python 初始化配置.py
cd AstrBot-master
uv sync
uv run main.py
```

启动器 EXE 仅支持 Windows x64。插件的额外依赖按各插件说明安装。
