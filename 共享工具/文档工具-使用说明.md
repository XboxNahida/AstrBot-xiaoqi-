# 通用文档工具箱云端用法

`文档工具箱.zip` 保留 PowerShell 入口、模块、Python/Node 辅助程序和回归脚本的完整目录结构。所有机器人共用这份工具包，执行时解压到当前已授权任务目录，不在全局共享目录写入文档、缓存或依赖。

```powershell
# 当前目录必须是本次任务工作目录。已有同名目录时先复用或另选目录，不覆盖任务文件。
Expand-Archive -LiteralPath 'C:\AstrBotTasks\tools\文档工具箱.zip' -DestinationPath .
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\文档工具箱\04_脚本\文档工具.ps1' 状态
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\文档工具箱\04_脚本\文档工具.ps1' 检查 '.\输入.docx'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\文档工具箱\04_脚本\文档工具.ps1' 提取文本 '.\输入.pdf'
```

支持命令：`状态`、`检查`、`预览`、`提取文本`、`转PDF`、`整理`、`清理缓存`。原工具不会自动下载依赖，缺少依赖会明确报错。

上传版仅调整 `工具配置.json` 的路径：工作区是解压后的工具箱，输出与缓存位于其内部；Python 默认使用当前任务根目录的 `.venv\Scripts\python.exe`。在任务虚拟环境安装 `文档工具-requirements.txt` 后可使用 DOCX/PDF 检查和提取。不要把 Python 路径改为机器人宿主环境，受限账户无权读取宿主程序。

DOC/DOCX 转 PDF 需要 LibreOffice，PDF 预览需要 Poppler，XLSX 检查和预览需要 Node.js 与 `@oai/artifact-tool`。本次只上传工具源码，不随包复制 Codex 私有运行时或安装这些额外依赖；具体功能以 `状态` 返回为准。Node 路径预留为任务目录下 `依赖\node\node.exe`，模块目录预留为 `依赖\node_modules`，实际安装后在解压副本配置。

共享工具包不会自动执行。运行结果包含文档内容时，只在当前任务内保存与发送。源工作区、私人文档、模板、成品及缓存没有上传。
