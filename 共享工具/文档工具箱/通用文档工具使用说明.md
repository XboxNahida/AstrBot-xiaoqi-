# 通用文档工具使用说明

## 运行方式

在 `Codex工作区` 目录中打开 PowerShell，使用统一入口：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\04_脚本\文档工具.ps1" 状态
powershell -NoProfile -ExecutionPolicy Bypass -File ".\04_脚本\文档工具.ps1" 检查 "<文件>"
powershell -NoProfile -ExecutionPolicy Bypass -File ".\04_脚本\文档工具.ps1" 预览 "<文件>"
powershell -NoProfile -ExecutionPolicy Bypass -File ".\04_脚本\文档工具.ps1" 提取文本 "<文件>"
powershell -NoProfile -ExecutionPolicy Bypass -File ".\04_脚本\文档工具.ps1" 转PDF "<DOC或DOCX>"
powershell -NoProfile -ExecutionPolicy Bypass -File ".\04_脚本\文档工具.ps1" 整理 "<目录>"
powershell -NoProfile -ExecutionPolicy Bypass -File ".\04_脚本\文档工具.ps1" 清理缓存
```

路径包含中文、空格或括号时必须使用引号。未知命令退出码为 `2`；输入或处理失败退出码为 `1`。

## 命令说明

- `状态`：检查工作区、缓存以及 Python、Node.js、LibreOffice、Poppler 和表格依赖。
- `检查`：支持 DOC、DOCX、PDF 和 XLSX；成功时输出 JSON。
- `预览`：Word/PDF 按页生成 PNG；XLSX 每个工作表生成一张 PNG，固定预览范围为 `A1:P40`。
- `提取文本`：支持 DOC、DOCX 和文本型 PDF，文本成品使用唯一文件名。
- `转PDF`：支持 DOC 和 DOCX，转换后验证页数与逐页预览数量后才发布 PDF 成品。
- `整理`：只读递归扫描指定目录，在 `03_成品输出` 生成 UTF-8 CSV 和中文 Markdown 清单。字段包含文件名、类型、大小字节、修改时间和完整路径。不移动、改名、覆盖或删除源文件；同名成品自动使用唯一名称。
- `清理缓存`：仅清理配置的缓存根目录，不删除源文件或成品。

## 目录分区

- `01_待处理`：待处理的文件副本或任务材料。
- `02_处理中`：人工核对或处理中的中间文档。
- `03_成品输出`：永久保留的报告、提取文本、PDF 和目录清单。
- `04_脚本`：工具源码、配置、辅助程序和测试。
- `05_模板`：可复用的文档或表格模板。
- `06_归档`：设计、实施记录与历史材料。
- 同级 `Codex缓存区（可删除）`：转换、渲染和依赖链接缓存，不是成品。

## 依赖与已知限制

工具不会自动下载或安装依赖。依赖缺失时，相关命令会用中文说明缺失项并以非零退出码结束，不伪造成品。

- 当前环境未安装 LibreOffice，DOC/DOCX 转 PDF 和 DOC 预处理未实机验证。
- 当前环境未安装 Poppler，PDF 逐页渲染及转 PDF 发布链路未实机验证。
- 当前环境未安装 PowerShell 7，已在 Windows PowerShell 5.1 下验证，PowerShell 7 尚未实机验证。
- 扫描型 PDF 不提供 OCR，因此“提取文本”可能返回空文本或仅有少量元数据文本。
