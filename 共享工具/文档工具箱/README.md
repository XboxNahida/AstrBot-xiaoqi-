# Codex 文档处理工作区

本目录用于整理 Word、DOC/DOCX、Excel、PDF、图片等文件的处理过程。

## 目录说明

- `01_待处理`：需要后续整理的文件副本或任务材料。
- `02_处理中`：正在编辑、转换或核对的中间文件。
- `03_成品输出`：最终交付的 Word、Excel、PDF 等文件。
- `04_脚本`：可重复运行的整理、转换和生成脚本。
- `05_模板`：以后可复用的表格、文档和版式模板。
- `06_归档`：已完成任务的历史成品和必要记录。

## 缓存区

同级目录 `Codex缓存区（可删除）` 用于存放临时转换文件、渲染图片、预览图和依赖缓存。没有文档处理任务正在进行时，可整个删除。

## 默认处理规则

1. 不直接覆盖用户的源文件，除非用户明确要求。
2. 最终文件放入 `03_成品输出`，临时文件放入缓存区。
3. 需要重复生成时，保留脚本到 `04_脚本`。
4. 清理缓存时不删除源文件、成品、模板和归档文件。

## 工具入口

统一入口为 `04_脚本\文档工具.ps1`，支持：

```text
文档工具.ps1 状态
文档工具.ps1 检查 <文件>
文档工具.ps1 预览 <文件>
文档工具.ps1 提取文本 <文件>
文档工具.ps1 转PDF <DOC或DOCX>
文档工具.ps1 整理 <目录>
文档工具.ps1 清理缓存
```

`整理` 只读递归扫描指定目录，把 UTF-8 CSV 和中文 Markdown 清单写入 `03_成品输出`，不改动源文件。表格预览固定为每工作表 `A1:P40`。

详细命令、依赖缺失行为和已知限制见 [通用文档工具使用说明](./通用文档工具使用说明.md)。工具不自动安装依赖；当前未实机验证 LibreOffice、Poppler 和 PowerShell 7，扫描型 PDF 不提供 OCR。
