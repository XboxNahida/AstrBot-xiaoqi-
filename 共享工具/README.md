# 全局共享任务工具

云端目录为 `C:\AstrBotTasks\tools`，所有机器人共用同一份工具文件。网页「任务管理」支持查看和上传；上传不会自动执行。

| 工具 | 用途 | 使用说明 |
| --- | --- | --- |
| 文档工具箱.zip | Word/PDF/XLSX 检查、提取、转换、预览和目录整理工具源码 | 文档工具-使用说明.md |
| Convert-ToUtf8.ps1 | 批量转换 C/H/MD/TXT 编码 | UTF8转换-使用说明.md |
| UTF8转换-启动工具.cmd | 有桌面环境时交互启动转换器 | UTF8转换-使用说明.md |

机器人使用方式：先列举并阅读工具及说明，在获得授权的独立任务目录运行。通用文档依赖见 `文档工具-requirements.txt`；UTF-8 转换器不需要 Python，后台任务必须传 `-SourceFolder`，不要弹出目录选择窗口。默认输出副本，只有用户明确要求才使用 `-Overwrite`。

此目录只包含工具源码、依赖说明和使用说明，不含用户文档、模板、聊天、任务数据库、账号或密钥。代码仓库中的 `共享工具` 目录可以手动复制到部署机器的共享工具目录。
