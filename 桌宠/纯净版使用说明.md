# 桌宠纯净源码版

本目录来自当前定制桌宠源码，保留桌面形象、动作、界面、云端桥接和测试。不包含模型密钥、配对信息、聊天记忆、答疑截图、录音、运行日志、虚拟环境或用户配置。首次启动使用源码默认配置，自动观察与语音建议在完成模型配置后手动启用。

## 安装和启动

建议 Windows 10/11 x64、Python 3.12。在本目录打开 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-companion.txt -r requirements-features.txt
.\.venv\Scripts\python.exe -m pip install pytest pytest-asyncio
Copy-Item -LiteralPath config.example.json -Destination config.json
.\启动桌宠.ps1
```

已有 config.json 时不要覆盖。源码入口为 original_main.py，经典版用 `-Mode classic`。FFmpeg 供音频格式处理，可在使用相关功能前安装并加入 PATH。构建 EXE 属可选步骤，源码运行不依赖 PyInstaller。

## 连接自己的机器人

服务器需安装本仓库的 astrbot_plugin_desktop_link 插件，以有效 HTTPS 证书代理 `/desktop/ws` 及 `/desktop/health`。先在插件配置中把 `public_url` 从回环占位地址改为自己的 HTTPS 根地址，再用机器人管理员账号私聊发送 `桌宠 配对 my-pc 我的电脑`；在桌宠设置的“云端连接”页读取配对信息并保存。云端地址填写自己的 `wss://服务器域名/desktop/ws`，本包不附原设备密钥或生产地址。

连接成功后由主要用户私聊请求机器人检查桌宠在线。服务健康和客户端连接不等同于动作完成，仍以实际回执为准。桌面操作与截图权限在本机设置中手动开启，未授权时不操作电脑。
