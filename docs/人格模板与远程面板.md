# 人格模板与远程面板

## 从已有人格创建

在「人格」页面点击「创建人格」，启用「从现有人格创建」，选择服务器上已经创建的人格。选择后自动载入人格说明、完整示例、工具、技能及自定义错误文案，并显示说明字数和示例对数；也可点击「复制到当前表单」重新载入。

修改副本名字和内容后保存。名字冲突会生成新的副本名，目标文件夹为当前创建位置。复制不修改原人格，不复制记忆或机器人绑定；示例中空的助手回复、全部能力的`null`与禁用能力的空数组保持原语义。

已打开的旧页面需要刷新，才能加载新版资源。本次发布同时包含Vue源码、三种语言文案、合成测试和正常构建的内置面板。

## 手机或其他电脑访问

服务器可在面板前配置HTTPS反向代理，供手机和其他电脑使用同一个网页入口。建议面板仅监听`127.0.0.1`，由独立HTTPS服务代理到实际面板端口，继续使用面板登录认证；任务和脚本接口保留本机监听。

域名、公网IP、证书、监听端口及代理自动启动需按自己的服务器配置。本仓库不包含个人服务器证书、私钥、账号、登录状态或真实站点配置，也不会替使用者自动开放端口。已部署的实例无需为了拉取这次源码重新配置网络。
