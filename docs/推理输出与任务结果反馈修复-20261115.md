# 推理输出与任务结果反馈修复

## 修复内容

- 统一清理助手生成的 `think`、`thinking`、`reasoning` 内部推理块，包括大小写、多块和未闭合的情况。推理块中的代码也会移除，正常正文的 Markdown 代码示例保留。聊天响应在工具恢复和语音处理前完成清理，任务通知沿用同一规则。
- 任务结果交给聊天模型整理时，按结构为结果和执行证据分配长度预算，不再直接截断序列化后的 JSON，避免结果字段丢失或 JSON 不完整。
- 成功任务的聊天主备模型均无法整理回复时，使用该任务已保存的公开结果摘要。合并回调按原会话和任务版本读取结果，保留凭据隐藏、内部推理清理和投递幂等。
- 显式静默标记在清理前识别；通知整理异常仅记录分类，不记录异常原文或凭据。

## 验证结果

- 公开副本七模块回归：353 项测试、45 项子测试通过，仅既有 `audioop` 弃用警告。
- 初始化和导出版内置更新阻断：7 项检查通过。
- 四项生产源码和两项合成测试通过 UTF-8 编译，增量静态检查没有新增诊断。
- 两项修复此前已在云端限定部署，完成四平台健康和实际类合成探针验证；真实平台的后续效果以正常聊天为准。

本次发布保留原公开人格、音色、脱敏预设及更新限制，不包含运行配置、聊天、记忆、任务数据库、日志回执、凭据或备份。Gemini 响应耗时实测未改变请求策略，不在本次修复范围内。
