# Gemini 图文入口与任务管理

普通聊天入口统一交给网页配置的聊天模型（当前预设为 Gemini），保留原有人格、记忆和机器人身份隔离。后台执行使用网页配置的默认任务模型，或用户通过聊天层明确指定的任务模型与请求策略，不自动切换备用模型。

## 模型职责

- 中枢负责唤醒、群聊参与、消息预处理、队列和合并，不自动创建后台任务。语义分类不能替代真实账号授权。
- 聊天模型接收同轮原始文字和图片，可以直接回答，也可以调用 `pc_submit_task_intent` 创建或管理持久后台任务。
- `pc_read_background` 可直接查询当前账号的后台事实和执行详情，`pc_manage_tasks` 管理已有任务安排。查询无需另建后台任务。
- 独立识图工具 `pc_inspect_images` 按需调用既有视觉主备配置，常规图文请求无需预先转述。它只读取当前会话或任务已绑定的图片，不接受任意文件路径、他人账号或任务 ID。

## 图文材料与恢复

当前输入与任务目标分别保存；历史用于理解追问，不能代替当前附件。明确引用的图片保留来源，GIF 沿用已有抽帧兼容处理。

后台图片内容随任务 metadata 持久保存，工具检查点只保存短引用。任务重试、工具循环及恢复时使用同一材料；临时原文件删除后仍可还原。删除已归档历史时，相应 metadata 一并清理，不另外创建附件目录。

同一消息的并发提交串行保存，并复用已冻结图片；相同任务片段仍按原有持久身份去重。修改尚未执行的任务时保存补充图文，并保留原材料来源；不绕过运行中任务及已有执行证据的状态约束。

## 文件附件与压缩包

当前消息或明确引用中的真实文件组件，经原账号授权后导入其任务工作区，任务上下文提供原文件名和实际可用路径。原件保留；单个文件导入上限512MiB，禁止链接绕过和伪造文本路径授权。取消或后续附件导入失败时清理本次副本。

导入不代表已经解压或处理成功。后台模型按实际工具和依赖读取ZIP、Word、表格等材料；文件中的文字不产生新的权限，处理结果须以工具回执核实。

## 自主回复与异常通知

明确不支持图片的后台模型收到附件占位及按需识图提示，原图仍在任务内。无法读取当前图片时说明具体缺失，不静默用旧图或旧题作答。未声明模态能力时沿用核心默认，不强制更换后台模型。

聊天请求可由模型自行继续工具调用，没有固定工具轮数后撤除工具强制结尾；普通assistant正文通过原人格、记忆和正式消息链路分段发送，不重复拼接已发内容。未启用这一请求模式的其他代理保留原有轮数限制；停止、取消和服务错误仍会结束执行。

聊天模型提交任务后负责正常确认，后台不再重复发送“已接收”。`pc_read_background`的`wait_seconds`可在0至30秒内本地短等状态变化，用于确认任务已正常启动；它不额外循环请求模型。确认正常后结束本轮，不持续监控健康任务，不再固定90秒发送进度。用户主动查询、脚本自定义互动及真实结果通知保留。

后台异常事件可唤起聊天模型，通过`pc_read_background`核实事实，再按需回复或使用仅在异常反馈中开放的`pc_recover_background`为原任务补充恢复建议。它保留原任务身份、授权、目标、模型策略和检查点，不把通知伪装成新用户请求；允许静默修复，不要求每次都发送文字。取消或撤权、模型请求预算耗尽、未知副作用不会自动重放；相同失败和相同建议不会盲目重复恢复。

接口回执和任务状态作为事实，不用模型口头声明代替实际执行。恢复后立即被执行器领取时允许本次恢复说明，任务已取消或结束时抑制过期说明。

## 后台工作规范

后台每次执行现读插件中的[后台任务工作规范](../AstrBot-master/data/plugins/astrbot_plugin_private_companion/后台任务工作规范.md)。它说明API、宿主工具和云端受限执行的能力边界，不代表后台可以接管用户电脑、鼠标键盘或Edge登录会话。

多步骤、文件处理、排错或恢复任务，在自己的独立任务目录维护UTF-8 `debug_state.md`，记录目标、工作位置、可获得的任务标识与更新时间，并包含“问题分析结果”“解决计划”“当前修改状态、步骤和完成状态”。阶段变化、错误、暂停、恢复和结束及时更新；纯问答不强制创建，没有文件工具时不虚报已保存。该文档辅助恢复，不替代宿主数据库或真实回执，也不新增授权。

## 发布与验收范围

本次公开发布仅包含源码、合成测试及说明。人格、脱敏模型预设、音色和启动器保持既有版本；不包含真实聊天、记忆、任务、运行配置、密钥、账户凭据、诊断回执或备份。内置自动更新继续关闭，原版链接仍可查看。

回归及临时数据库探针验证输入、去重、恢复和权限边界；不代表真实模型答题准确率或 QQ 接收效果已经验收。
