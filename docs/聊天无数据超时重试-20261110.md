# 聊天无数据超时重试

聊天流式请求连续30秒未收到数据时，当前模型重试一次；两次均无数据才进入配置的备用模型，备用模型同样最多尝试两次。模型配置的超时时间更短时沿用更短值，收到有效分片后重新计算空闲时间。

仅对本轮尚未交出响应的无数据超时执行重试，不重放已经输出的内容或已完成的工具操作。用户取消和总时限异常不按空闲超时重试。重试日志明确标记 `retrying once (2/2)`，便于区分同模型重试与备用切换。

后台任务沿用自己的请求预算和超时设置。本次不改变联网工具、人格、模型选择或备用配置。
