# 任务模型选择与重连

网页“模型”页可配置后台任务默认模型、单次请求超时和最多请求次数。默认使用 `openai/gpt-6-sol`，单次120秒，总共最多3次请求，即首次请求加两次重试。后台任务停用备用模型，聊天及识图原有备用配置继续有效。

聊天层通过 `pc_list_task_models` 读取模型目录，直接复用网页下拉菜单的同一取数函数；返回已配置模型的 `id`、名称、类型和模型名，不暴露密钥。按目录返回的准确 `id` 选择模型，不能自行猜测标识。

`pc_submit_task_intent` 可为单个任务设置 `model_id`、`timeout_seconds`、`max_attempts`；省略时使用网页默认，管理已有任务时保留其已保存策略。`max_attempts` 包含首次请求，参数不会改变其他任务或共享提供器的设置。执行权限仍由真实账号授权决定。

首次模型请求失败，聊天层沿用人格主动说明模型波动、正在重连同一模型；中间重连不重复进度播报，预算耗尽后再次汇报并询问是否换模型。任务状态、材料和成功工具步骤持久保存，指定新模型重试时沿检查点继续，不重放已成功步骤；过期或取消任务的重连通知不发送。

次数预算对应同一模型步骤的连接尝试，不限制整个任务所需的正常工具轮次。成功执行工具后，下一轮模型请求重新使用独立预算。工具出错仍反馈给任务模型，由其修正方案，不能将工具错误等同于模型请求耗尽。

模型策略固定到任务，工具排列保持稳定；SDK单次超时确实覆盖到HTTP请求，不修改共享客户端默认值。是否获得缓存命中及费用优惠，仍取决于模型服务与中转站支持，不能仅凭固定模型保证。

发布只包含源码、合成测试和脱敏预设，不包含真实任务记录、聊天、记忆、密钥及云端诊断回执。合成验证不能代替真实模型波动、QQ投递和聊天语气验收。
