# 统一会话队列与后台更新

本次同步统一会话队列，以及其依赖的此前已验证源码：Codex 独立后台对话、近期聊天上下文、Gemini 自主管理记忆、多个附件和历史媒体顺序、脚本通知回执。

## 消息如何处理

- 同一机器人、同一会话的连续文字、图片和附件按到达顺序入队，保留完整输入和真实账号身份。
- 模型生成期间的新输入在继续点提供给 Gemini；最终尚未发送的草稿最多修订一次，后续输入排下一轮，避免持续输入导致一直不回复。
- 后台任务回调也进入同一队列。当前聊天已吸收回调事实时，通知标记为已处理，不再另开一条通知；没有聊天时按顺序生成主动反馈。
- 脚本主动消息共用队列和会话锁，保留原取消条件。等待期间续租，发送结果不确定时不盲目重发。
- 程序管理顺序、隔离和发送事实，具体接话仍由模型决定，人格不因这次更新改写。

Codex 后台代码需要另行安装兼容的 Codex CLI 并配置所需运行环境；源码仓库不附带云端安装凭据、密钥或私人任务。非 GPT 模型仍使用原生后台执行路径。网页保留引擎、模型和思考程度配置。
