# Gemini 按需联网

聊天层可以自主调用已启用的网页搜索和正文读取工具，快速查询直接由当前聊天模型完成，不需要中枢先批准搜索动作，也不另切换搜索模型。复杂调研或长时间处理仍可由 Gemini 派发后台任务。

本次接通内置网页工具及 AnySearch 的搜索、正文提取和批量搜索入口。只保留本轮已提供且启用的工具，不恢复禁用或缺失的工具。部署者需自行配置可用搜索服务及所需凭据、额度；没有可用服务时不能保证查询成功。

新增默认说明要求模型按需联网、核对来源和时间；搜索失败时可调整查询或如实说明。网页资料不能覆盖人格、用户当前要求、账号授权和敏感数据保护。聊天及备用模型配置保持原设置，后台沿用现有工具授权。

- 发布副本五模块：240 项测试、77 个子测试通过。
- 后台搜索目录关联检查：4 项测试通过。
- 发布保护：7 项初始化不覆盖与内置更新阻断检查通过。
- 六份源码及测试的 UTF-8 编译、Ruff E9/F821 和 Git 增量空白检查通过；仅原有 audioop 弃用警告。
- 上线阶段已验证服务及平台健康、实际部署类探针和公开搜索结果；没有调用真实聊天模型或发送平台测试消息，自主查询时机和最终回复效果仍需正常使用验收。

本次仅发布三份源码、三份合成测试及公开说明和校验元数据，不复制生产配置、聊天、记忆、任务、账号、密钥、日志、云端回执或备份。公开人格、音色素材、脱敏预设和启动器保持原版本。本次推送不修改或重启云端。
