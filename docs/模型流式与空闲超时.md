# 模型流式与空闲超时

## 调整范围

当前 OpenAI 兼容模型和 Anthropic/Kimi 的聊天、中枢判断、图片理解、后台任务推理统一在内部接收流式分片；需要完整响应的调用方仍获得完整响应。内部流式不代表平台聊天按字发送。

原生图片生成与编辑、语音合成与识别、向量嵌入和普通工具 HTTP 请求保持各自协议。

## 超时与重试

- 沿用原请求超时作为连续无数据时限，超过60秒封顶60秒。例如10秒、35秒保持，120秒变为60秒。
- 正文、推理和工具参数的原始分片都会刷新活动计时，避免持续生成大工具参数时被误判无响应。
- 中枢仍保留原30秒上限；每个模型最多请求3次，含首次。原始判断与结构纠正共享次数，主模型和备用模型分别计数。
- 单次模型请求保留600秒总边界。后台整体任务仍可多轮执行，不按600秒统一结束。
- 取消、连接关闭和检查点恢复保留；半截流及未完成的工具参数不会作为完整工具请求执行。
- 后台任务旧120秒配置会在运行时规范为60秒空闲时限。公开预设保持，网页与接口说明已更新。
- 后台每次模型请求会记录开始、接收完成、取消或失败及耗时，方便确认执行情况；日志不记录正文或工具参数，不逐个Token刷屏。

## 验证及边界

工具调用轮的空正文或前置说明不会清理最终回答所需的待回复状态。中枢已经用新事件替代旧事件时，新事件保持独立处理，避免旧回复过期而新消息又被旧执行器消耗。后台异常反馈兼容核心标为`tool`的合法模型工具调用，可继续只读查证与授权内纠正；不因此扩大权限。

发布前在公开副本执行定向回归、UTF-8编译、两套网页脚本语法、增量Ruff及发布保护检查，结果记录于根目录导出检查报告。

流式和中枢策略与既有上线最终文件SHA一致，查询回复修复另行验证上线。离线合成测试和已有云端健康检查不替代真实模型回复效果验收；发布验证不调用收费模型或代发消息，运行中任务结束前不重载云端。

人格、全部公开预设、两份音色、启动器及内置更新阻断保留。真实密钥、聊天、记忆、任务、用户附件、云端运维回执和回滚均不属于公开发布内容。
