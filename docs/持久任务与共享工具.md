# 持久任务与共享工具

## 任务如何执行

中枢识别任务后，把要求、真实发起人、机器人和会话写入持久任务清单。回复模型也可以根据当前用户原话补交中枢漏判的任务，但不能自行扩大权限；同一消息和片段按来源去重。聊天模型、任务模型及备用模型仍在网页配置，不限定后台必须使用某一厂商。

任务执行独立于当前聊天回复，保存模型、状态、步骤和工具回执。网页「任务管理」可以查看、暂停、取消、修订和核实任务；权限按机器人、群和真实用户账号核验，不使用昵称授权。主要用户可以给指定群友授予任务权限和到期时间，群友不能转授权；已有有效任务授权可使用普通任务能力，撤销或过期立即停止。管理机器人程序本身不属于工作目录授权。

中枢用 `task_mode=tools/reasoning` 表达执行或推理倾向。模式与兼容参数 `use_workspace` 不再隐藏已有授权工具，工具目录按真实身份、当前配置和授权动态刷新。模型可以先分析，再核对资料或改用其他授权工具；语义标签不能授予权限。

普通工具报错会保存脱敏正文并交回模型，由模型纠正参数、换方案或报告受阻；不再固定执行30步或只许纠错几次。可重试模型故障按15秒、随后60秒退避并保留检查点。模型决定整体完成、受阻或确需用户信息，程序区分模型完成报告与实际工具回执。已成功步骤不自动重做，结果不明先查询核实，不能盲目重放；进程重启产生的不明副作用仍保留核实保护。

任务默认超过 90 秒仍未完成才补一次真实进度，完成或失败另行通知；网页可调整等待时间（0～120 秒，0 关闭）。任务失败不会被说成聊天模型不可用。定时提醒复用原有定时器；资讯监测的检查周期、允许通知时段、次数和变化条件按任务保存，没有新结果时可保持安静。

## Windows 文件与命令权限

默认任务根目录为 `C:\AstrBotTasks`。不同机器人、群和真实用户的执行目录隔离；全局共享工具目录为 `C:\AstrBotTasks\tools`。设置工作目录本身不会开启命令权限。

文件写入、命令和依赖安装必须由经过验证的受限 Windows 账户执行。部署脚本在 `deployment/配置受限任务执行.ps1`，`Plan` 模式只生成计划，账户准备需要管理员／SYSTEM 权限。运行时账户协调器使用固定脚本和路径串行准备，完成隔离、联网、虚拟环境、安装和进程回收验证后才接受就绪证明；准备失败保持关闭。普通文件查询使用独立的固定只读接口，不要求准备其他用户的执行账户。默认公开预设不包含任何真实账号、授权、凭据或就绪证明。

这套执行器针对 Windows 部署；其他系统不能直接套用 Windows 账户准备。不要为绕过失败而让任务使用宿主管理员身份。任务可以在自身授权目录安装依赖，不能因此读取机器人密钥或记忆库。

宿主根据真实账号授权自动提供工作目录和可用工具，不要求模型手填 `use_workspace`，账户在真正需要执行时才准备。准备暂时失败也会作为未执行反馈交回模型，不阻止先查询或采用其他方案。执行前注入自身目录和可读群友目录，不应递归扫描 `C:\AstrBotTasks` 根目录。

使用 `pc_task_workspace(action="info")` 查看真实位置，`action="list"` 列文件，`action="read"` 读取文本；指定宿主返回的 `workspace_id` 可只读访问其他可见工作区。普通读取启用后可发现其他任务工作区，也可使用 `pc_task_read_file` 或固定 `read/list` 接口按本地绝对路径查询普通资料和源码。消息、历史、任务详情与互动通道仍绑定原机器人、会话及账号。

内部令牌、密钥、凭据、私有运行数据和数据库不共享；文本返回前清理敏感字段及已配置密钥，重解析点、硬链接、网络和设备路径不接受。跨工作区只提供固定读取能力，写入、命令和依赖安装仍限自己的授权目录，不能改写他人工作区或机器人核心。通道缺ID时先 `list/open`，有效期不足可 `renew`，先 `list_scripts` 核对已有脚本再安排，避免重复。真实撤权、关闭和取消仍立即阻止继续操作。

脚本失败、中断或到期会保存退出码与脱敏根因，并按稳定事件ID幂等交给同一身份的任务模型处理；模型能看到原始要求和回执。程序不自动重跑原脚本，也不为恢复额外发送确认及进度刷屏。API监听暂时失败会自动重试，脚本调度不再等待慢聊天生成。既有未来pending脚本保持；历史已终态记录不自动重提。

聊天与识图遇到明确供应商故障文本时尝试已配置备用；失败视觉摘要不缓存，旧故障缓存失效。正常解释或引用错误文字不触发切换，已经输出的流式文字不重复生成。中枢格式错误在当前调用内纠正一次，失败决定不复用，缺少任务快照只省略相关上下文；正常成功仍每事件一次请求。

脚本互动的消息采集、发送、历史查询、停止与调度接口见 [脚本互动接口使用说明](脚本互动接口使用说明.md)。任务完成需有明确的完成报告；受阻保留原因和已完成步骤，需要补充信息时等待用户，不能把一次查询成功当成整体完成。

## 使用共享工具

仓库 `共享工具/` 包含完整文档工具源码、打包 ZIP、UTF-8 转换器和中文说明。可以把其中顶层文件通过网页「任务管理」上传到全局工具目录；上传只保存文件，不会自动运行。所有机器人可读取同一份工具，运行前仍需通过任务授权。

文档工具按模块组织。云端列表只展示顶层文件，因此使用 `文档工具箱.zip` 保留完整结构。机器人应先阅读 `文档工具-使用说明.md`，再解压到当前授权任务目录；输出、缓存和依赖留在任务目录，不写回共享工具库。已有同名文件不会被静默覆盖。

Python 文档依赖列在 `文档工具-requirements.txt`。DOC/DOCX 转 PDF 另外需要 LibreOffice，PDF 预览需要 Poppler，XLSX 检查／预览需要 Node.js 和 `@oai/artifact-tool`。这些运行时没有随工具复制，也没有在服务器自动安装；具体可用功能以工具的「状态」命令为准。

UTF-8 转换器在后台使用时必须指定 `-SourceFolder`，避免弹出目录窗口；默认输出转换副本，覆盖原文件须另有用户明确要求。详细参数见 `共享工具/UTF8转换-使用说明.md`。

## 验证范围

本次公开副本验证覆盖持久任务、授权、执行器、通知、工具上传、模型请求预算和旧定时器桥接；使用合成任务和临时数据库。文档工具另用合成 DOCX／PDF 检查、DOCX 文本提取、目录整理和编码转换验证，输入原文档字节未改变。没有使用真实用户文档测试，也没有调用付费模型或发送 QQ 验收消息。

公开内容保留原人格、模型预设、两份克隆参考音频和启动器；不包含真实聊天、长期记忆、任务库、账号密钥或云端账户凭据。内置自动更新仍被阻断，参考上游请访问 [AstrBot 官方仓库](https://github.com/AstrBotDevs/AstrBot)。
